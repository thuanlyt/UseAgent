# Enforce reviewer authority for release transitions

## Objective

Prevent implementation workers from self-approving review evidence or closing tasks as done; require a registered supervisor, reviewer or release_gate identity for review evidence and review-gated transitions while preserving worker report flow.

## Acceptance criteria

- [ ] Only registered supervisor/reviewer/release_gate identities can append review evidence or transition a reported task through needs_review to done
- [ ] A worker can still report completed work and add non-review evidence, but cannot self-approve or self-close
- [ ] Reviewer identity may differ from assigned worker without violating assignment ownership
- [ ] Existing lifecycle, demo, full QA and documentation remain green
